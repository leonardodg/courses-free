# Operação

Colocar a plataforma no ar e mantê-la funcionando.

| Documento | O que é |
|---|---|
| [`configuracao-inicial.md`](configuracao-inicial.md) | a ordem em que os plugins precisam ser configurados, e por que a ordem importa |

O detalhe de cada setting fica no `README.md` do plugin correspondente. Este
diretório cuida do **encadeamento** entre eles — o que costuma dar errado não é
um setting isolado, é a ordem.
