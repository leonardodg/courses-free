# Design System & Guide Styles: Moodle Theme Foundation (`leonardodg`)

## 1. Color Palette (Tokens)
- **Primary Accent / Blue:** `#007AFF` (Buttons, active states, focus rings, interactive elements)
- **Background Dark:** `#121212` (Global body background)
- **Surface Elevation:** `#1E1E1E` (Cards, navbar, modals, and container backgrounds)
- **Text High Emphasis:** `#FFFFFF` (Headings, primary text, high-contrast labels)
- **Text Medium Emphasis:** `#B0B3B8` (Secondary text, descriptions, inactive states)
- **Borders / Dividers:** `#3A3B3C` (Subtle borders, container separators)

## 2. Typography (Global)
- **Font Family:** `Inter`, sans-serif
- **Hero Title:** 64px / Bold (`700`)
- **H1 Headline:** 48px / Semi-Bold (`600`)
- **H2 Subtitle:** 36px / Semi-Bold (`600`)
- **H3 Card Title:** 24px / Semi-Bold (`600`)
- **Body Text:** 16px / Regular (`400`) — Line height: 1.6
- **Caption / Small:** 14px / Regular (`400`)

## 3. UI Components & Elements
### Buttons
- **Primary Button:** Background `#007AFF`, Text `#FFFFFF`, Border-radius `8px`
- **Primary Hover:** Background `#3394FF`
- **Secondary Button:** Border `1px solid #007AFF`, Text `#007AFF`, Background transparent
- **Inverted Button:** Background `#FFFFFF`, Text `#121212`

### Inputs & Fields
- **Input Field:** Background `#1E1E1E`, Border `1px solid #3A3B3C`, Text `#FFFFFF`, Border-radius `8px`
- **Focus Ring:** Border `2px solid #007AFF`

### Cards & Layout Containers
- **Card Container:** Background `#1E1E1E`, Border-radius `8px`, Padding `24px`, Box-shadow `0 4px 6px rgba(0,0,0,0.3)`
- **Course Cover Image Ratio:** 2:1 (Ideal for Moodle course grid items)

### Navigation & Icons
- **Navbar Height:** 64px (Desktop) / 50px (Mobile)
- **Navbar Background:** `#1E1E1E` with bottom border `#3A3B3C`
- **Icon Actions:** Flat layout with color accent highlighting on state change.
